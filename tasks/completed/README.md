# Completed work - cold storage

Dated, append-only records of finished work moved out of `tasks/plan.md` and
`tasks/todo.md`. One file per working day, `plan-completed-YYYY-MM-DD.md`.

A day's file is immutable once that day passes. Corrections belong in the living
docs, not here. Retired per-feature specs move in whole, as
`SPEC-FEATURE-NAME-YYYY-MM-DD.md`.
